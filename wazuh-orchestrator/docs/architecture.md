# Architecture

The V1 package keeps infrastructure access outside the analysis engine:

- `discovery.py` discovers Easy-Wazuh topology from files and optional Docker adapters.
- `metrics.py` and `wazuh_api.py` collect host, Docker and Wazuh signals.
- `analyzer.py` diagnoses worker, host, indexer, cluster and NGINX pressure.
- `scaler.py` enforces baseline, max, confidence and host safety gates.
- `backends/compose.py` generates Docker Compose override data and shell-free Compose commands.

Easy-Wazuh conventions discovered from the existing installer:

- installation root: `/opt/wazuh/wazuh-docker`
- single-node compose: `/opt/wazuh/wazuh-docker/single-node/docker-compose.yml`
- multi-node compose: `/opt/wazuh/wazuh-docker/multi-node/docker-compose.yml`
- multi-node master naming: `wazuh-manager01.<suffix>`
- initial worker naming: `wazuh-manager02.<suffix>`
- multi-node frontend: existing `nginx`
- certificates: generated by the official `wazuh-certs-generator` image into `config/wazuh_indexer_ssl_certs`

`INTEGRATION_VALIDATION_REQUIRED`: worker certificate generation for new nodes must be validated on a real Easy-Wazuh/Wazuh Docker host before real scaling is considered production-safe.
